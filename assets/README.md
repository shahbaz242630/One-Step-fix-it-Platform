# Assets Folder

This folder should contain icon files for the desktop application.

## Required Files

- `icon.png` - 512x512 PNG for Linux
- `icon.ico` - Windows icon file
- `icon.icns` - macOS icon file

## Creating Icons

You can create icons using:
1. Online tools like https://www.icoconverter.com/
2. Design tools like Figma, Photoshop, or Canva
3. Icon generators

## Recommended Icon Design

For a financial management platform, consider:
- Calculator symbol
- Currency symbol (AED)
- Chart/graph symbol
- Building/home symbol
- Combination of the above

Keep it simple, professional, and recognizable at small sizes.

## Temporary Placeholder

For now, the app will work without custom icons and use default Electron icons.
To add your own:
1. Create/obtain your icon files
2. Place them in this folder with the names above
3. Rebuild the application
